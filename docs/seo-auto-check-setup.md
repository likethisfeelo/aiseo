# 검색 결과 자동 확인 — API 키 발급 및 설정 가이드

## 개요

이 기능은 설정한 키워드로 네이버/구글을 검색하여 내 사이트가 검색 결과에 노출되는지 자동으로 확인합니다.

**지원 채널:**
- 네이버: 웹 검색, 블로그, 이미지 (무료 25,000회/일)
- 구글: 웹 검색, 이미지 (무료 100회/일)

---

## 1단계: 네이버 검색 API 키 발급

### 1-1. 네이버 개발자 센터 접속

1. https://developers.naver.com 접속
2. 우측 상단 **로그인** (네이버 계정)

### 1-2. 애플리케이션 등록

1. 상단 메뉴 **Application** → **애플리케이션 등록** 클릭
2. 다음 정보 입력:
   - **애플리케이션 이름**: `AISEO 검색 확인` (자유롭게)
   - **사용 API**: `검색` 선택 (체크박스)
   - **환경 추가**: `WEB 설정` 선택
   - **웹 서비스 URL**: `https://aiseo.tips`
3. **등록하기** 클릭

### 1-3. API 키 확인

등록 완료 후 **내 애플리케이션** 페이지에서:
- **Client ID**: `XXXXXXXXXXXX` 형태의 문자열
- **Client Secret**: `XXXXXXXXXX` 형태의 문자열

이 두 값을 복사해 둡니다.

### 네이버 API 무료 한도
| 항목 | 한도 |
|------|------|
| 일일 호출 횟수 | 25,000회 |
| 한 번 요청 시 최대 결과 | 100개 |
| 검색 타입 | webkr (웹), blog (블로그), image (이미지) |

## 2단계: 구글 Custom Search API 키 발급

### 2-1. Google Cloud 프로젝트 생성

1. https://console.cloud.google.com 접속
2. Google 계정으로 로그인
3. 상단 프로젝트 선택 → **새 프로젝트** 클릭
   - 프로젝트 이름: `AISEO` (자유롭게)
4. **만들기** 클릭

### 2-2. Custom Search API 활성화

1. 좌측 메뉴 **API 및 서비스** → **라이브러리**
2. `Custom Search API` 검색
3. **Custom Search API** 클릭 → **사용** 버튼 클릭

### 2-3. API 키 생성

1. 좌측 메뉴 **API 및 서비스** → **사용자 인증 정보**
2. 상단 **+ 사용자 인증 정보 만들기** → **API 키** 클릭
3. 생성된 API 키를 복사
4. (선택) 보안을 위해 **키 제한** 설정:
   - **API 제한**: Custom Search API만 허용

### 2-4. 검색 엔진 (CSE) 생성

1. https://programmablesearchengine.google.com 접속
2. **새 검색엔진** 클릭
3. 설정:
   - **검색할 사이트**: `*.aiseo.tips` 입력 후 추가
   - **검색엔진 이름**: `AISEO Search` (자유롭게)
   - **전체 웹 검색**: 반드시 **켜기** (중요!)
4. **만들기** 클릭
5. 생성된 검색엔진의 **검색 엔진 ID (cx)** 를 복사
   - 형태: `a1b2c3d4e5f6g7h8i` 같은 문자열

### 구글 CSE API 무료 한도
| 항목 | 한도 |
|------|------|
| 일일 호출 횟수 | 100회 (무료) |
| 유료 | $5 / 1,000회 추가 |
| 한 번 요청 시 최대 결과 | 10개 |
| 검색 타입 | 일반 웹, 이미지 (searchType=image) |

> 키워드 5개 기준: 웹 5회 + 이미지 5회 = 10회/1회 확인.
> 하루 최대 10번 자동 확인 가능.

## 3단계: 환경변수 설정 (관리자)

발급받은 4개의 키를 CDK 배포 시 환경변수로 설정합니다.

### 방법 1: 터미널에서 직접 설정 후 배포

```bash
# 환경변수 설정
export NAVER_CLIENT_ID=발급받은_네이버_Client_ID
export NAVER_CLIENT_SECRET=발급받은_네이버_Client_Secret
export GOOGLE_CSE_API_KEY=발급받은_구글_API_Key
export GOOGLE_CSE_ENGINE_ID=발급받은_검색엔진_ID

# CDK 배포
cd infra/cdk
npm run build
npx cdk deploy
```

### 방법 2: .env 파일에 추가

프로젝트 루트의 `.env` 파일에 추가:

```
# Search API Keys
NAVER_CLIENT_ID=발급받은_네이버_Client_ID
NAVER_CLIENT_SECRET=발급받은_네이버_Client_Secret
GOOGLE_CSE_API_KEY=발급받은_구글_API_Key
GOOGLE_CSE_ENGINE_ID=발급받은_검색엔진_ID
```

> 주의: `.env` 파일은 git에 커밋하지 마세요 (이미 .gitignore에 포함되어 있어야 함)

## 4단계: 사용 방법 (사용자)

### 키워드 설정
1. 사이드바 **SEO 현황** 클릭
2. **검색 결과 스냅샷** 탭에서 **추적 키워드** 설정
3. 쉼표로 구분하여 키워드 입력 (최대 10개)
   - 예: `천안 가방, 수제 가죽가방, 핸드메이드 가방`
4. **저장** 클릭

### 자동 확인 실행
1. **검색 결과 자동 확인** 버튼 클릭
2. 약 10초 후 결과가 타임라인에 자동 기록됨
3. 키워드별로 각 채널의 노출 여부/순위 확인 가능

## 제한사항 및 FAQ

### Q: 구글 API 한도를 초과하면?
A: 구글 채널만 스킵되고 네이버 결과는 정상 표시됩니다. 에러 메시지가 함께 표시됩니다.

### Q: 네이버에서 100위 밖이면?
A: "노출 없음"으로 표시됩니다. 네이버 API는 최대 100개 결과를 반환합니다.

### Q: 구글에서 10위 밖이면?
A: 무료 API는 한 번에 10개 결과만 반환하므로, 10위 밖이면 "노출 없음"으로 표시됩니다.

### Q: API 키 없이 사용할 수 있나요?
A: 아니요. 최소 네이버 API 키는 필요합니다. 네이버만 설정하면 네이버 채널만 확인됩니다.

### Q: 자동으로 매일 확인할 수 있나요?
A: 현재는 수동 버튼 클릭 방식입니다. 향후 EventBridge 스케줄러를 추가하면 매일 자동 실행이 가능합니다. (docs/seo-snapshot-automation.md 참고)
