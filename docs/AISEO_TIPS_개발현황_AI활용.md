# AISEO.TIPS 개발 현황 및 AI 활용 정리

> 정부지원사업 제출용 — "AI를 어떻게, 어디까지 활용해 개발했는가"
>
> 작성 기준일: 2026-07-03 · 서비스: **AISEO.TIPS** (https://aiseo.tips)

---

## 1. 한 줄 정의

**AI 시대의 소상공인·1인기업·스타트업이 "AI로 만든 홈페이지"를 검색엔진에 잘 노출되도록 최적화(SEO)하고, 자동으로 배포·운영까지 할 수 있게 해주는 웹 플랫폼.**

사용자는 AI(ChatGPT·Claude 등)로 원하는 사이트를 만들고, AISEO.TIPS에 올리면
→ 구조·SEO 자동 검증 → 리포트 확인 → 원클릭 배포(`{내사이트}.aiseo.tips`) → 운영 코드(구글 애널리틱스·서치콘솔·네이버) 삽입까지 한 흐름으로 끝납니다.

> 슬로건: **"AI로 만들고, SEO로 알린다"** — AI로 원하는 사이트를 만들고, 10년 전문가의 핵심 SEO 노하우로 검색엔진에서 쉽게 찾아지도록 만들어드립니다.

---

## 2. 해결하는 문제 (Why)

AI 도구로 홈페이지를 "만드는 것"은 쉬워졌지만, 소상공인에게는 여전히 3가지 벽이 남습니다.

| 문제 | 현실 | AISEO.TIPS의 해결 |
|---|---|---|
| **① 링크만 생기는 AI 사이트** | AI가 만들어준 결과물을 실제 웹에 올리는 방법을 모름 | ZIP 업로드 → 원클릭 배포 (서버·도메인 지식 불필요) |
| **② 매달 나가는 호스팅비** | 사이트 유지에 계속 비용 발생 | S3/CloudFront 서버리스 구조로 저비용 운영 |
| **③ 아무도 못 찾아오는 사이트** | 검색엔진에 노출이 안 됨 | SEO 자동 검증 + 검색 노출 진단 + 운영 코드 자동 삽입 |

---

## 3. AI를 어떻게 활용하고 있는가 (핵심)

AISEO.TIPS에서 AI는 **① 제품이 제공하는 가치**와 **② 제품을 만든 개발 방식** 두 축 모두에 적용되어 있습니다.

### 3-1. 제품 안에서의 AI 활용 (사용자에게 제공하는 가치)

1. **AI 사이트 제작 전제 워크플로우**
   서비스 전체가 "AI로 사이트를 만든다"를 전제로 설계됨. 사용자는 AI에게 프롬프트로 사이트를 만들게 하고, AISEO는 그 결과물을 **검색엔진 친화적으로 다듬어 세상에 내보내는 뒷단**을 자동화합니다. (AI 사이트 제작 프롬프트 + SEO 기본 셋팅을 1시간 강의로 교육)

2. **SEO 자동 검증 엔진**
   업로드된 사이트를 자동 분석 — `index.html`·`robots.txt`·`sitemap.xml` 존재 여부, `<title>`·`meta description` 등 검색 최적화 필수 요소를 규칙 기반으로 자동 점검하고 리포트로 제공.

3. **검색 노출 자동 진단 (외부 검색 API 연동)**
   네이버 검색 API(웹/블로그/이미지)와 구글 커스텀 서치 API를 연동해, 내 키워드가 실제 검색 결과에서 **몇 페이지·몇 위에 노출되는지**를 자동 수집·진단하는 SEO 자동 체크 기능. (`google-search`, `naver-search`, `naver-blog`, `naver-place`, `instagram-hashtag` 등 8개 채널 스냅샷)

4. **콘텐츠 자동화 교육 (준비 중)**
   AI(ChatGPT·Claude)를 활용한 SEO 블로그 글 자동 생성, SNS 콘텐츠 일괄 발행, 고객 리뷰 수집·답변 자동화 커리큘럼을 제품 로드맵에 편성.

5. **업종별 성장 로드맵 진단**
   현재 비즈니스 단계를 진단하고 업종 맞춤 5단계 성장 플랜(비즈니스 트랙 + 디지털 마케팅 트랙)과 우선순위·예상 지표를 제시하는 컨설팅형 기능.

### 3-2. 개발 방식으로서의 AI 활용 (AI 페어 프로그래밍)

**AISEO.TIPS는 처음부터 AI 코딩 에이전트(Claude Code)와의 페어 프로그래밍으로 개발되었습니다.** 정부지원사업 관점에서 "AI를 실제 업무에 어떻게 도입했는가"의 대표 사례입니다.

- **개발 방식**: 기획자/대표가 자연어로 요구사항을 전달 → AI 에이전트가 코드 작성·수정·배포 스크립트까지 실행 → PR(Pull Request) 기반 코드 리뷰 후 병합.
- **정량 지표(2026-05~06 기준)**:
  - 전체 커밋 **124개**, 이 중 AI 에이전트 브랜치(`claude/*`) 및 PR 병합이 **약 45건** — 기능 개발의 상당 부분이 AI 협업으로 진행.
  - **약 1개월(2026-05-25 ~ 06-25)** 만에 아래 "4. 개발 현황"의 전체 기능 세트를 1인 체제로 구축.
- **효과**: 프론트엔드(React) · 백엔드(AWS Lambda 29종) · 인프라(CDK/CloudFront) · 배포 자동화 스크립트를 **1인 + AI** 조합으로 대기업 개발팀 수준의 범위를 커버. 외주·다인 개발팀 없이 빠른 반복(iteration)과 낮은 인건비로 MVP를 넘어선 완성도를 달성.

## 4. 개발 현황 — "어디까지 만들었나"

MVP("업로드 → 검증 → 배포" 1개 흐름)를 넘어, 실제 운영 가능한 수준의 통합 플랫폼으로 확장 완료.

### 4-1. 규모 요약

| 항목 | 규모 |
|---|---|
| 프론트엔드 페이지 | **43개** (공개/대시보드/관리자) |
| 백엔드 서버리스 함수(Lambda) | **29개** |
| 기술 스택 | React 19 · TypeScript · AWS 서버리스 풀스택 |
| 서비스 도메인 | 운영 `aiseo.tips` / 개발 `dev.aiseo.tips` |
| 개발 기간 | 약 1개월 집중 개발 (AI 페어 프로그래밍) |

### 4-2. 완성된 핵심 기능

**◎ 사이트 운영 파이프라인 (핵심 흐름 — 완료)**
- 회원 가입/로그인 (AWS Cognito, 이메일·카카오 로그인 연동)
- 사이트 생성 및 다중 사이트 선택 관리
- ZIP 업로드 (presigned URL 방식 — 대용량 안전 업로드)
- 구조·SEO 자동 검증 + 리포트
- 원클릭 배포 (S3 + CloudFront, 서브도메인 자동 발급)
- 운영 코드 삽입 (GA4 / 구글 서치콘솔 / 네이버 웹마스터)
- 커스텀 도메인 연결 설정

**◎ SEO·분석 (완료/운영)**
- SEO 상태 대시보드 (SEO 점수화)
- 검색 노출 스냅샷 자동화 (네이버·구글 검색 API 연동, 8채널)
- 애널리틱스 연동 (Meta Pixel 연결 카드 등)

**◎ 콘텐츠 & 마케팅 (완료)**
- **블로그 CMS** — 공개 블로그 + 어드민 전용 발행, 카테고리·태그·예약발행·조회수·SEO 메타(OG 태그)·프리렌더링(SSR)까지 구현
- **라이브러리(자료실)** — 커버/포스트 관리, 감사(audit) 기능
- **이벤트/강의 랜딩** — 2026 이벤트(무료/유료/1차), 강의(course2026), 지원사업(support2026) 페이지
- **B2B 페이지** 및 B2B 상담 위젯
- 뉴스레터 구독, 상담/문의 위젯, 고객 리뷰(스티커 배치·튜토리얼 등 인터랙션)

**◎ 커머스 기반 (구축)**
- 브랜드/상품/서비스/스토어 페이지 및 관리 핸들러

**◎ 관리자 백오피스 (완료)**
- 사이트 목록·상세 관리, 회원 관리, 상담/이벤트 신청 관리
- 블로그·라이브러리 CMS 어드민, 마케팅 어드민
- **쿼터(사용량) 정책 관리** — 멤버십/플랜별 이미지·저장용량·ZIP 용량 상한(hard cap) 정책 엔진

**◎ 인프라·운영 자동화 (완료)**
- AWS CDK 기반 IaC(코드형 인프라), CloudFront 서브도메인 라우팅
- 운영/개발(prod/dev) 이원화 배포 스크립트
- 프리렌더링(SEO용 정적 HTML 생성) 파이프라인

### 4-3. 기술 아키텍처

```
사용자(AI로 사이트 제작)
      │  ZIP 업로드
      ▼
Frontend (Vite + React 19 + TypeScript)
      │
   API Gateway ──► AWS Lambda (Node.js 20, 29개 함수)
      │                 │
      │            DynamoDB (사이트/리포트/블로그/회원 등)
      │                 │
   S3 (업로드/사이트) ──► CloudFront (CDN) ──► {siteId}.aiseo.tips
      │
  Cognito (인증) · Route53 + ACM (도메인/TLS) · CDK (IaC)
```

- **Frontend**: Vite · React 19 · TypeScript · React Router 7 · Tiptap(리치 에디터)
- **Backend**: AWS Lambda(Node.js 20) · API Gateway · DynamoDB(온디맨드) · S3 · CloudFront
- **Auth/DNS**: AWS Cognito · Route 53 · ACM
- **IaC/배포**: AWS CDK · 자동 배포 스크립트(prod/dev)
- **외부 연동**: 네이버 검색 API · 구글 커스텀 서치 API · GA4 · 구글 서치콘솔 · Meta Pixel · 카카오 로그인

## 6. 정부지원사업 서술용 핵심 문장 (그대로 활용 가능)

> 당사는 소상공인이 AI로 제작한 홈페이지를 검색엔진에 최적화(SEO)하여 배포·운영할 수 있게 하는 웹 플랫폼 **AISEO.TIPS**를 개발·운영하고 있습니다. AI는 두 층위에서 활용됩니다.
>
> 첫째, **제품 차원**에서 사용자가 생성형 AI(ChatGPT·Claude)로 만든 사이트를 자동으로 SEO 검증하고, 네이버·구글 검색 API와 연동해 실제 검색 노출 순위를 진단하며, AI 기반 콘텐츠 자동화 기능을 확장하고 있습니다.
>
> 둘째, **개발 방식 차원**에서 AI 코딩 에이전트와의 페어 프로그래밍을 도입하여, 자연어 요구사항을 코드로 구현하고 PR 기반으로 검증·배포하는 방식으로 프론트엔드·백엔드·인프라 전체를 1인 체제로 구축했습니다. 그 결과 약 1개월 만에 43개 화면·29개 서버리스 함수 규모의 통합 플랫폼을 실서비스 수준으로 완성하였습니다.
